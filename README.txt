ARISE — Player System

Open index.html in Chrome or Edge. Keep all files in this folder together, including alert.mp3 and touch.mp3.

Sound files are the user-provided recordings: alert.mp3 for opening/notifications and touch.mp3 for taps and checkboxes. Browsers require a first click/tap before they allow sound playback.

Code & Build focus timer: 45 minutes; quest reward: 15 XP. Daily reset countdown is beside the Daily Quest list, not inside Body Training.

Use RESET PLAYER LEVEL for two confirmation warnings. It resets XP and allocated attributes, while keeping journal, skills, achievements, and quest history. Export a JSON backup before resetting if you want a recovery copy.

Data remains local to this browser/device; it does not cloud-sync automatically.
